 HelloPortType.java es la interfaz que contiene la firma de los métodos que corresponden a las operaciones que proporciona nuestro sistema SOAP. 
 
 3 Implementar la interfaz
 
 En "src/main/java" crearemos una ruta de subdirectorios "com/ejemplo/hello" (el package)
 
 en IntelliJ IDEA lo veremos como com.ejemplo.hello, ahí crearemos una nueva clase java con nombre "HelloPortTypeImpl.java" esta será la clase que implementa la interfaz HelloPortType.java.
 
 poner el siguiente contenido
 
 
 package com.ejemplo.hello;

import javax.jws.WebService;

@WebService(
        serviceName = "HelloService",
        portName = "HelloPort",
        targetNamespace = "http://www.examples.com/wsdl/HelloService.wsdl",
        endpointInterface = "com.ejemplo.hello.HelloPortType"
)
public class HelloPortTypeImpl implements HelloPortType {

    @Override
    public SayHelloResponse sayHello(SayHelloRequest parameters) {
        SayHelloResponse resp = new SayHelloResponse();
        String name = parameters.getFirstName();
        // String last = parameters.getLastName();
        // System.out.println("lastname" + last);
        if (name.isEmpty()){
            resp.setGreeting("Hola anónimo amigo!!");
        }else{
            resp.setGreeting("Hola " + name + "!" );   //+ last + "!");
        }

        return resp;
    }

    @Override
    public SayGoodbyeResponse sayGoodbye(SayGoodbyeRequest parameters) {
        SayGoodbyeResponse resp = new SayGoodbyeResponse();
        String name = parameters.getFirstName();
        resp.setFarewell("Adiós " + name + "!");
        return resp;
    }
}


En este punto marcará errores en el código. El problema es que las referencias de los nuevos elementos del proyecto Maven no se han cargado aún correctamente. Ir a a la ventana de Maven y, en su barra superior, hacer click en la flecha del icono de fechas circulares que forma un bucle y seleccionar "Reload All Maven Projects". Los errores desapareceran.


Explicar


Crear un servidor y un cliente

Hacer una nueva clase Java en com.ejemplo.hello con el nombre "HelloServer.java" y poner el siguiente contenido


package com.ejemplo.hello;

import javax.xml.ws.Endpoint;

public class HelloServer {

    public static void main(String[] args) {
        String address = "http://localhost:8080/HelloService";

        HelloPortTypeImpl implementacion = new HelloPortTypeImpl();

        Endpoint.publish(address, implementacion);

        System.out.println("HelloService publicado en " + address);
        System.out.println("Pulsa Ctrl+C para detener.");
    }
}


Hacer una nueva clase Java en com.ejemplo.hello con el nombre "HelloClient.java" y poner el siguiente contenido:


package com.ejemplo.hello;

public class HelloClient {

    public static void main(String[] args) {
        // Crear el "service" a partir de la clase generada
        HelloService service = new HelloService();

        // Obtener el port que implementa HelloPortType
        HelloPortType port = service.getHelloPort();

        // Construir solicitud sayHello
        SayHelloRequest helloReq = new SayHelloRequest();
        helloReq.setFirstName("Juan");

        SayHelloResponse helloResp = port.sayHello(helloReq);
        System.out.println("Respuesta sayHello: " + helloResp.getGreeting());

        // Construir solicitud sayGoodbye
        SayGoodbyeRequest byeReq = new SayGoodbyeRequest();
        byeReq.setFirstName("Juan");

        SayGoodbyeResponse byeResp = port.sayGoodbye(byeReq);
        System.out.println("Respuesta sayGoodbye: " + byeResp.getFarewell());
    }
}



Guardar todos los cambios

En maven hacer doble click en compile


4 Ejecutar

en la petaña de HelloServer.java, hacer clic sobre el icono de ejecutar (hay dos iconos, cualquiera está bien, porque hacen lo mismo) y seleccionar "Run HelloServer.main()"

Esto abrirá una ventana de terminal que muestra 

HelloService publicado en http://localhost:8080/HelloService
Pulsa Ctrl+C para detener.


El servidor sigue corriendo hasta que lo detengamos. Nota cualquier cambio en las clases generadas o auto generadas requiere que se reinicie el servidor.

Ejecutar el cliente

en la pestaña de HelloClient.java, hacer clic sobre el icono de ejecutar (hay dos iconos, cualquiera está bien, porque hacen lo mismo) y seleccionar "Run HelloClient.main()"


Esto abrirá una nueva pestaña de terminal (al lado de la del servidor) que debe mostrar:

Respuesta sayHello: Hola Juan!
Respuesta sayGoodbye: Adiós Juan!

Process finished with exit code 0
